## Flex vs Grid

Jag använder `display: grid` på `.tabla`.
Där har jag avgångar med tid och destination.
Jag vill ha dem i rader och kolumner, därför passar Grid bra här.

Jag använder `display: flex` på `.kort-rad`.
Där har jag destinationskort bredvid varandra.
Här behöver jag mest en riktning, därför passar Flex bra.

Om jag använder Flex på `.tabla` kan alla avgångar försöka ligga på samma rad
och det kan bli trångt.

Om jag använder Grid på `.kort-rad` fungerar det också,
men jag behöver inte Grid där eftersom Flex räcker för mina kort.
